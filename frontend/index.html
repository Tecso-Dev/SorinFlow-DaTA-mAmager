    اسکرپینگ جدید
    با انتخاب «شخصی» یا «مشاور املاک»، آگهی‌هایی که نوع آگهی‌دهنده‌شان مشخص نیست ذخیره نمی‌شوند — پس نتیجه کمتر ولی دقیق است.
    با انتخاب تاریخ، فقط آگهی‌های منتشرشده در همان روز اسکرپ می‌شوند
    خالی بگذارید تا همه آگهی‌های آن تاریخ اسکرپ شوند؛ برای محدود کردن، عدد وارد کنید
    هر این تعداد آگهی، به شمارهٔ بعدیِ ذخیره‌شده سوییچ می‌کند. عدد کمتر = چرخش بیشتر = پیامک احراز هویت کمتر. ۰ = بدون چرخش.

    وقتی روشن باشد، هر بازدیدکننده‌ای صفحهٔ «در حال بروزرسانی» را می‌بیند و پنل و API برای همه بسته می‌شود — به‌جز شما. تا وقتی خودتان خاموشش نکنید روشن می‌ماند، حتی اگر سرور دوباره راه‌اندازی شود.

    زمان‌شمار فقط به بازدیدکننده نشان داده می‌شود؛ با تمام‌شدن آن سایت خودبه‌خود باز نمی‌شود — باز کردن سایت همیشه با خود شماست.

    بکاپ و نسخهٔ خارج از سرور در حال بررسی...

    هر شب ساعت ۰۳:۳۰ از همهٔ جدول‌ها یک نسخه گرفته می‌شود و ۱۴ نسخهٔ آخر روی سرور می‌ماند. اما سرور همان جایی است که داده‌ها هستند — با یک ربات تلگرام، هر نسخه به گوشی شما هم می‌رسد و از دست رفتن سرور، داده را از بین نمی‌برد.

    return fetch(upstream, { method: request.method, headers, body: request.method === 'GET' ? undefined : request.body });
  }
