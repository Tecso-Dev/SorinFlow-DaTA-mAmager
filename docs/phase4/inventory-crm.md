Card (_cqCard 9955) actions -> POST /crm/leads/{id}/call {outcome, note?, callback_at?, visit_at?}: پاسخ داد (asks a note), پاسخ نداد / مشغول (no note), بازدید (asks Jalali date+time -> visit_at ISO; creates a calendar event server-side), دوباره زنگ بزن (presets 1h/3h/tomorrow 10:00/custom -> callback_at), علاقه ندارد / شماره اشتباه (confirm first).
